# Fonts

Inter was obtained through the Google Fonts CSS API. Its SIL Open Font License is included alongside the font files. Fonts are served locally; page loads do not contact Google Fonts.

Comic Sans MS is used from the visitor's system when installed; its proprietary font files are not included in this repository. Comic Neue (regular and bold) is the self-hosted fallback for other devices. The unmodified TTF files come from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/comicneue), with their SIL Open Font License in `Comic-Neue-OFL.txt`.
